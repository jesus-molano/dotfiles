# Research Primary Sources

Define the exact decision and freshness requirement before searching. Prefer official documentation, specifications, repositories, release notes, maintainers, or original studies. Use secondary sources only to discover leads, never as the final basis for a material claim.

For each conclusion, record the source, publication/version/date, direct supporting evidence, and whether it is fact or inference. Reconcile conflicts instead of silently selecting one source. State what is unknown and the smallest next verification step. Cite links close to the claims they support; quote only the minimum needed. Return the research in the response unless the user requests a specific output file. Research is read-only by default: do not modify the repository or an external system. Never collect or disclose credentials, private configuration, or personal data.
