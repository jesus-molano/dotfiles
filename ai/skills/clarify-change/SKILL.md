# Clarify Change

Inspect the nearest instructions, current behavior, ownership, constraints, and
existing decisions before asking. Resolve facts from the repository or primary
sources; do not turn discoverable facts into questions.

Ask at most three focused questions when a choice changes product behavior,
security, data handling, compatibility, cost, rollout, or authority. Present
the concrete options and their consequence. Assume small reversible details,
state the assumption, and continue.

Return a compact brief: observable outcome, scope and non-goals, constraints,
acceptance checks, chosen decisions, assumptions, and open blockers. Do not edit
code or create a durable specification unless the user requests it.
