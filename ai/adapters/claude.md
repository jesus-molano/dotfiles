# Adaptador Claude Code (CLI y pestaña Code de Desktop)

- Lee `AGENTS.md` junto con `CLAUDE.md` en cada proyecto. Las instrucciones globales
  no sustituyen los contratos del repositorio. No crees instrucciones paralelas divergentes.
- `reuse-scout` usa Haiku. Los revisores usan Opus con esfuerzo alto y herramientas de lectura.
- Conserva el modelo y esfuerzo elegidos localmente. Usa el modelo de la suscripción por defecto.
- `bypassPermissions` elimina diálogos técnicos; conserva los límites humanos de
  publicación, eliminación, datos y autorización definidos arriba.
- Usa los comandos y herramientas disponibles en Claude; no inventes herramientas de Codex.
- Para Linear usa `linear` de lectura. La escritura requiere un MCP temporal y la skill
  `linear-workflow`. Mantén tokens, memoria automática e historial fuera de dotfiles.
